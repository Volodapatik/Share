# Share

Швидка P2P передача файлів між телефонами / комп’ютерами.

**Жива версія:** https://volodapatik.github.io/Share/

## Як користуватися

1. На **відправнику** натисни «Створити кімнату» → з’явиться код і QR.
2. На **отримувачі** введи код (або відскануй QR) і натисни «Приєднатися».
3. Коли з’явиться «Підключено» — на відправнику обери файл і надішли.
4. Прогрес видно на обох сторонах. Файл автоматично пропонується для завантаження.

## Технології

- PeerJS (WebRTC DataChannel)
- Пряме P2P з’єднання (без сервера для файлів)
- STUN від Google
- Один короткий код + QR

## Обмеження

- Обидва пристрої повинні бути онлайн.
- За симетричним NAT може не з’єднатися (рідко).
- Для дуже великих файлів (>1 ГБ) краще використовувати спеціалізовані інструменти.
